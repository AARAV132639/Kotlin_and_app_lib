## Phase 1 — Language Fundamentals

1. **Implementation of programs using variables, data types, operators, conditions, and loops.**

2. **Implementation of functions, arrow functions, callbacks, default parameters, and rest/spread operators.**

3. **Implementation of arrays, objects, strings, Maps, Sets, and their built-in methods.**

4. **Implementation of destructuring, optional chaining, nullish coalescing, and template literals.**

5. **Implementation of exception handling using try, catch, finally, and custom errors.**

6. **Implementation of ES modules using import/export and modular project structure.**
