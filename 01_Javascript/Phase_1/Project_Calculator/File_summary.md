# File Summary

1. Package.json : Project configuration and ES moduel setup

2. Index.js : application entry point

3. calculator.js : core calculator logic

4. Operatios.js" contains the actual mathematical operations

5. History.js: manages calculator's calculation

6. statistics.js: calculates statistics from calculator history

6. errors.js: contains custom error classes

7. utils.js: contains reusable helper functions that don't belong specifically to the calculator engine
