# Axios

## Why do we need Axios?
- Axios acts as the communication layer between frontend and backend

## Where Axios is actually used?

- **Authentication system**: Send login and registration requests
- **File upload service**: Upload files to the backend
- **Dashboard**: retrieve user information and statistics
- **CRUD application**: Create, read, update and delete records 

## Key distinctions to remember

- **Rest API**: Defines how client and servers communicate through resources and HTTP methods
- **HTTP client**: A tool used by an application to make HTTP requests
- **Fetch API**: Browser's built in http client
- **Axios**: Third party http client library
